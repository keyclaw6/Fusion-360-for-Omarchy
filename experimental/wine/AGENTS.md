# Unfinished standalone Wine experiment

This subtree is research, not the default installation path. Read README.md here
and the root INSTALL.md. Do not activate it or migrate a working GE prefix
automatically. Complete packaging and independent operational review are required
before recommending it to users.

Keep all binaries, prefixes, logs, designs and account/session data outside Git.
Use a separate private prefix and pinned runtime; never the system Wine prefix.
Preserve the root implementation and do not alter global graphics drivers.
Coordinate desktop control with the user and any other agent.
