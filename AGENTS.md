# Fusion 360 for Omarchy — agent instructions

Read README.md and INSTALL.md before installing. The repository root is the
default GE-Proton implementation. experimental/wine/ is unfinished research;
do not install it or switch runtimes automatically.

Use the desktop user's normal home and documented default state directories.
This project does not depend on a private implementation brief or another
repository. Preserve existing designs, unsynced work and unrelated installations.
An installation request does not authorize deleting another application's data.

Keep prefixes, runtime binaries, account/session state, callback URLs, logs,
screenshots containing private data, and user designs outside Git. Never request
that users paste authentication tokens or passwords into repository files.
Use Autodesk's normal browser sign-in with the user.

Read compatibility-lock.json and verify hashes; do not silently choose latest
versions or alter expected hashes merely to make a download/build pass. A changed
Fusion build or host configuration needs a fresh operational review.

The Hyprland helper owns only its marked block and private recovery records.
Do not edit global graphics drivers or unrelated desktop settings. Coordinate
exclusive desktop/MCP access during GUI testing. Finish native modals and document
loading before issuing MCP requests.

A launched window or successful API response is not application acceptance.
Verify actual rendering, native modeling, file round trips, window behavior and
a cold restart. Record untested areas and concrete failures honestly.

For source changes, follow CONTRIBUTING.md. Preserve upstream license notices
and keep the root installer independent of the experimental subtree.
